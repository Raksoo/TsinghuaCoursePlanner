Paste from the course system

Paste the lines of a course row from the Tsinghua system — stacked or as a table row. Separate several courses with a blank line. The time format 2-6(week 1-16) is read as weekday‑block.

Add a course manually

For courses with fixed times instead of a block code — such as the SEM electives from the MBA schedule (8:00–11:25, 13:30–16:55, 19:00–22:00). This same form is used to edit an existing course — click any course in the Course list to open it here.

Weeks applies to every meeting below together — it's the set of semester weeks (1–18) this course runs in, regardless of which weekdays it meets on.

Meetings

One row = one recurring weekly time slot. Most courses need only one — but a course that meets on two different weekdays (e.g. Monday and Wednesday) needs two rows: click Add meeting for the second one. “Apply block code” replaces all rows below with what the code describes, rather than adding to them.

Data & sharing

Courses live in your browser only. The file itself carries no data — export your list as JSON to pass it on, or export to .ics to bring your schedule into another calendar app.

Sharing: send this HTML file (it runs offline, just double-click it). To take over your selection as well, the other person imports the exported JSON file.

Calendar import: “Export to calendar” opens a dialog where you pick the week range and courses first. On Android, open the downloaded file with the Google Calendar app, or import it into Google Calendar on desktop — it then syncs to your phone automatically.
