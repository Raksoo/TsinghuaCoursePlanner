Data & sharing

Courses live in your browser only. The file itself carries no data — export your list as JSON to pass it on, or export to .ics to bring your schedule into another calendar app.

Share & back up your plan

Copy share link is easiest: it copies a link carrying your whole course list — send it to a friend and, when they open it, they're asked whether to load your plan. The JSON file does the same via a file instead of a link.

Calendar & print

Both open a dialog to pick courses (and, for the calendar, the week range) first. On Android, open the downloaded .ics file with Google Calendar, or import it on desktop — it then syncs to your phone. Printing always renders a real timetable; “All weeks · max load” also labels each course with the specific weeks it runs in, since overlapping cards there rarely all meet at once.

⚠️ Double-check weeks & credits

Weeks are read from the file when it lists them (e.g. (week 1-8)); otherwise a course defaults to 1-16. Credits, course number and instructor aren't in the export at all. Set the correct Weeks and CP below before adding — or fix them later in the course list.
